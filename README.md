# 🛡️ SOC Terminal Tools & Active Recall Tests

Welcome to my active recall repository. This directory contains a collection of Python scripts and defensive automation tools built entirely from scratch.

### The Methodology
Every script in this repository is the result of a "blank file test." My daily learning loop involves:
- **Zero IDEs:** Writing raw logic in `nano` without auto-complete or safety nets.
- **Active Recall:** Forcing syntax and architecture retrieval from pure memory.
- **Error-Driven Execution:** Debugging stack traces in real-time to solidify low-level comprehension.

### Contents
Currently, this repository focuses on **Security Operations Center (SOC)** capabilities, including:
- Core logic and control flow testing
- File I/O operations and log parsing
- IP management and network automation scripts

Feel free to explore the code. If you have any feedback or optimize a script, let me know!
